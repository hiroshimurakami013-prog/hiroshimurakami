# Design skills

These are the UI and design skills Solender AI uses on its projects. Because they
live in `.claude/skills/`, Claude Code loads them automatically for anyone who opens
this repo; nothing to install. Invoke one by name (for example `/impeccable` or
`/redesign-existing-projects`), or just describe the task and Claude picks the
right one.

| Skill | Use it for |
| --- | --- |
| `impeccable` | Designing, critiquing, auditing or polishing any screen. The main one. |
| `redesign-existing-projects` | Upgrading existing UI without breaking it (audit, then targeted fixes). |
| `design-taste-frontend` | Avoiding generic, templated-looking UI on new screens. |
| `high-end-visual-design` | Fonts, spacing, shadows and card structure that read as premium. |
| `minimalist-ui` | Calm, editorial, low-noise layouts. |
| `emil-design-eng` | The small details: press states, easing, timing, transitions. |
| `apple-design` | Fluid, physical motion and the design foundations behind it. |
| `animate` | Building a specific animation the right way. |
| `review-animations` | Reviewing motion code against a high bar. |
| `improve-animations` | Auditing all motion in the app and planning fixes. |
| `find-animation-opportunities` | Finding places that should animate (and rejecting the rest). |
| `animation-vocabulary` | Naming a motion effect you can describe but not name. |
| `pick-ui-library` | Choosing a library for a frontend task. |
| `prototype` | Building several genuinely different versions of a UI piece to compare. |

The project's own design rules (tokens, surfaces, badges, shell) are in the
"Design system" section of `CLAUDE.md` at the repo root. The skills give the
general taste; `CLAUDE.md` says how it applies here.
